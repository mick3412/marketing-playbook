# 1 品牌策略

受眾與定位清楚了，後面每一段文案的品質都會跟著提高；成果寫進產品設定檔，兩本手冊共用。

**這一步要產出：** .agents/product-marketing.md

## 要做

- [ ] **1.1 受眾研究**：寫出受眾的十大問題、慣用語、現在的解法、解法失效的地方和情緒；聚焦他們目前的階段
  - 幾種做法：(a) 從評論、論壇、影片留言收集原話（customer-research 技能）；(b) 用證據檢查受眾假設（twb-persona-evidence 技能）；(c) 提示詞範本 01 受眾研究
  - 受眾研究用 customer-research 技能收原話（S1-10）
  - 客戶訪談和諮詢通話留逐字稿，從原話整理受眾語言庫（S1-07，待試）
  - 在 Reddit 找正在問相關問題的人，揭露身分、真心幫忙，產品只在真的回答問題時才提（S1-08，待試）
- [ ] **1.2 受眾語言庫**：整理三類原話：痛點語言、願景語言、自我描述；用他們日常的說法，不用行話
- [ ] **1.3 語氣檔**：分析負責人的寫作範例：句子結構、詞彙、語調、開場與結尾、例子的用法，寫成第二人稱的寫作指引
  - 幾種做法：(a) 給 3–5 篇本人寫的文字讓 AI 分析；(b) 提示詞範本 04 品牌語氣；(c) WEN Prompt 01 品牌語氣（S39）；(d) NotebookLM 文案手冊（S41）
  - 語氣和視覺規則做成共用的設定，大家都從同一份出發（S1-02，待試）
  - 用 3–5 篇自己寫的貼文建語氣指南，先分析、不急著寫（S1-05，待試）
- [ ] **1.4 定位與差異化**：第一人稱 70–90 字的定位聲明（幫助誰、對方處境、交付成果、方法、可信證據）；三項差異：獨特方法、可量化成果、服務的細分市場
  - 幾種做法：(a) product-marketing 技能；(b) 提示詞範本 05、06；(c) brand-strategist 代理（還沒有品牌時從零建立；已有品牌不要用）
  - 定位與差異化先讀 product-marketing 技能（S1-09）
  - 寫出「適合你」和「不適合你」兩段（S1-03，待試）
  - 重大行銷決策用顧問團：各自回答、匿名互評、主席收斂成一個下一步（S1-06，待試）
  - 還沒有品牌時，用 brand-strategist 代理從零建立品牌；已有品牌只做審查（S1-11，待試）
- [ ] **1.5 內容支柱**：三到五個以信念或觀察為基礎的支柱，彼此不重疊，各自連到受眾在意的成果
  - 幾種做法：(a) content-strategy 技能；(b) 提示詞範本 03
  - 新帳號起步順序，讓定位、關鍵字和互動訊號一致（S1-04，待試）
- [ ] **1.6 寫進設定檔**：把 1.1–1.5 寫進 `.agents/product-marketing.md`，標上日期；限制規則另成一段
